# <center> **LLM Projects**

Collection of my projects focused on **Large Language Models**, Retrieval-Augmented Generation (RAG), and modern LLM-powered applications.

---

### 📁 Projects

- **[AI Tutor Bot](AI-Tutor-RAG-Cloud/)**  
  RAG-based Telegram bot that serves as a personal AI tutor for technical disciplines. Users can upload their own study materials (PDF/DOCX), and the bot answers questions with source references and generates quizzes.


---

### 🛠 Technologies & Approaches

**Core Technologies**
- OpenAI / Cloud.ru / other LLM APIs
- `SentenceTransformer` embeddings
- `FAISS` vector database
- `aiogram` / `Telegram Bot API`
- `LangChain` / `LlamaIndex` (in some projects)

**Key Techniques**
- Retrieval-Augmented Generation (RAG)
- Document chunking and indexing
- Prompt engineering
- Grounded generation with source attribution
- Evaluation of RAG systems
- Telegram bot development
